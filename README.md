## 🚀 Projeto em destaque

### [InspectAI — Industrial Anomaly Detection](https://github.com/HugoLeandro/inspectai-industrial-anomaly-detection)

Sistema de detecção e localização de anomalias industriais utilizando **PyTorch** e o dataset **MVTec AD 2**.

O projeto contempla:

* Treinamento e avaliação de modelos de visão computacional
* Detecção de anomalias em nível de imagem e pixel
* Comparação entre Autoencoder e PatchCore
* Avaliação com AUROC, Average Precision, Recall, IoU e Dice
* API de inferência com FastAPI
* Containerização com Docker
* Deploy no Google Cloud Run
* Testes automatizados e organização voltada para produção
